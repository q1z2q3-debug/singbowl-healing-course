## 八、丁夏操作规范（教材原文）

> 教材 1.3.9 / 1240 行

**适用场景**：耳鸣者替代太空人疗愈；疗愈开始与结束唤醒

**操作步骤**：
1. 距耳朵约 24寸（80厘米）敲击丁夏
2. 迅速移到耳朵 3寸（10厘米）处
3. 停留 5秒 或等声音渐消
4. 移回原来位置
5. 持续进行 3～5分钟

**被疗愈者姿势**：冥想或平躺

**丁夏尺寸**：8-10CM 最为合适

**音质选择**：泛音以悦耳、悠长为最佳

## 九、操作后注意事项（教材原文）

- 疗程结束后给个人一杯温水，提醒一整天都要多补充水分（3.3 流程8）
- 清淡饮食、睡前泡脚等（3.3 流程8）
- 心轮舒压理气需在专业音疗指导下进行（3.1.6）
- 女性保养类需在专业人士指导下进行（3.1.9）
