# 开源颂钵疗愈师培训教材

整理并开源了一份完整的颂钵疗愈师培训教材，GitHub 地址：

**https://github.com/q1z2q3-debug/singbowl-healing-course**

教材源自《颂钵疗愈师培训 7.0》课程，涵盖五大章节：

1. **初识颂钵** — 钵体认知、制作、选钵、使用技法
2. **理论课题** — 声音、振动、能量、疗愈原理、经络穴位
3. **实践操作** — 16 类案例、音乐会演奏、个案流程
4. **颂钵生命智慧** — 疗愈师修养、元气修复
5. **自然疗法** — 呼吸、瑜伽、芳香、水晶、冥想等
