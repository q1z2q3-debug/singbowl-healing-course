# 颂钵疗愈安全指南

> 本文档将教材中分散的禁忌提示、安全性要求与操作边界整理为独立清单，供疗愈师在个案与集体疗愈前逐项核查。**所有条款均来自《课程教材-颂钵疗愈师培训.md》原文，未添加任何推测性内容。**

---

## 一、疗愈的边界（教材原文）

- 颂钵疗愈**不同于医学治疗**：医学治疗针对肉体病痛，对治症状，需借助药物或手术；颂钵疗愈是了解疾病背后的原因（不良情绪、固有观念），利用疾病去探索心智、情感等更深层面的健康。（第四章）
- 无医生身份者，**不得进行医疗手术、诊断开药，也不得对外宣称可以治疗病症**。（4.2.1）
- 心轮舒压理气、女性妇科调理等疗愈**需要在专业音疗（人士）的指导下进行**。（3.1.6、3.1.9）

---

## 二、绝对禁忌（教材明确记载）

以下情况**不可**进行对应颂钵操作：

| 禁忌对象 | 禁止的操作 | 教材原文/位置 |
|---------|-----------|--------------|
| **耳鸣者** | 太空人疗愈 | "耳鸣者，不宜操作，可通过丁夏进行"（3.1.3.6） |
| **孕妇** | 心轮舒压理气 | "不适用于所有人，例如孕妇、心脏病患者等需要谨慎使用"（3.1.6） |
| **心脏病患者** | 心轮舒压理气 | 同上（3.1.6） |
| **月经期女性** | 颂钵疗愈 | "女性在进行颂钵疗愈时，也要注意避免在月经期进行"（3.1.15） |
| **有宗教信仰/心理健康/生理疾病/金属植入物者** | 疗愈场域净化（个案） | 流程3 疗愈场域净化："禁忌（健康调查表）宗教信仰 & 心理健康 & 生理疾病 & 金属植入物"（3.3） |

## 三、操作前检查清单

### 3.1 个案操作前（依据 3.3 流程2 课前沟通）

对每位被疗愈者完成以下沟通与确认：

- [ ] **症状与需求**：是否有身体疼痛、压力和焦虑等问题
- [ ] **疗愈目标**：希望通过颂钵疗愈实现什么（缓解疼痛、放松身心、平衡能量等）
- [ ] **健康状况**：是否有慢性疾病、过敏等问题（据此调整疗愈方法和使用的颂钵）
- [ ] **疗愈时长与费用**：确保被疗愈者对过程有清晰了解
- [ ] **疗愈师经验**：介绍自己的证书/培训背景、疗愈方法理念
- [ ] **疗愈环境**：说明疗愈室氛围、需携带物品
- [ ] **疗愈前准备**：是否需要禁食或停止某些药物
- [ ] **疗愈过程说明**：如何使用颂钵、被疗愈者需做什么、注意事项
- [ ] **疗愈后建议**：需要休息多长时间、做哪些事情、进行多少次疗愈

### 3.2 健康调查表核查（依据 3.3 流程3）

- [ ] 宗教信仰（尊重与确认，不强行引导）
- [ ] 心理健康状况
- [ ] 生理疾病状况
- [ ] 是否有金属植入物

### 3.3 唯一性确认（教材明文禁忌）

- [ ] 非月经期（3.1.15）
- [ ] 非孕妇（3.1.6）
- [ ] 无心脏病史或已在专业音疗指导下（3.1.6）
- [ ] 耳鸣者不做太空人疗愈，改用丁夏方案（3.1.3.6）

### 3.4 疗愈师自身准备（依据 3.3 流程1）

- [ ] 自我能量保护：冥想、观呼吸、颂钵连接
- [ ] 芳香精油使用（建议保卫复方精油）
- [ ] 以"爱心、静心、聆听、观察"的态度操作，不用于表演或发泄（第四章）

## 四、操作中的安全要点（教材原文）

| 环节 | 安全要点 | 教材位置 |
|------|---------|---------|
| **持钵** | 无金属准备、感知与无影响式持钵 | 1.3.2 |
| **放钵** | 吸气时接触鼓胀的腹部，双手持续托钵承担一半重量，另一半缓慢传导到被疗愈者身上；不把全部钵的重量转移；跟随呼吸在下一次吸气时完全稳定放置 | 1.3.6 |
| **敲击力度** | 敲击方式或大或小，可根据场域、颂钵位置与疗愈者身心状态灵活变通 | 1.3.7 |
| **丁夏禁忌** | 耳朵是脆弱器官：距耳约24寸（80厘米）敲击，迅速移到3寸（10厘米）停留5秒或等声音渐消，再移回，持续3-5分钟；被疗愈者冥思或平躺；丁夏8-10CM 最合适，泛音悦耳悠长为佳 | 1.3.10 |
| **撤钵** | 依次敲击、声音渐消后撤钵 | 3.3 流程6 |
| **唤醒** | 使用丁夏唤醒，恢复细胞层与神经层觉知，身心平衡 | 3.3 流程7 |

---

## 五、操作后关怀（教材原文）

- [ ] 给被疗愈者一杯温水，提醒一整天都要多补充水分（3.3 流程8）
- [ ] 建议清淡饮食、睡前泡脚等（3.3 流程8）
- [ ] 交流疗愈体验（可引导描述身体感受、情绪体验、思维状态；分享感悟；探讨颂钵作用；分享使用技巧；交流颂钵文化）（3.3 流程8）

---

## 六、音乐沙龙会注意事项（3.2.4 教材原文）

- 观察疗愈者的状态，做灵活调整
- 可从海底轮方向移动，依次演奏各个脉轮的音乐
- 整个过程中保持颂钵、被疗愈者、钵音与自我的连接与觉知

---

## 七、安全边界声明

- 本指南内容全部提取自教材原文，未新增推测性禁忌或数值。
- 面对教材标注"需补充课堂笔记"（如疏肝理气步骤2循肝经敲击、3.1.12长期偏头痛等）的操作细节，请以培训课堂笔记或专业导师指导为准。
- 有任何健康状况疑问时，建议先咨询正规医疗机构，再决定是否接受颂钵疗愈。
