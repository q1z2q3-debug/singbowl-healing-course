# 开源颂钵疗愈师培训教材：一套完整的声音疗愈知识体系

如果你正在寻找系统的颂钵疗愈学习资料，或者想了解声音疗愈与身心自愈背后的科学原理，这个项目可能正好适合你。

我整理并开源了一份《颂钵疗愈师培训 7.0》课程教材，以 Markdown 格式发布在 GitHub 上，涵盖从颂钵基础认知到高阶疗愈技法的完整知识体系。

## 项目简介

**GitHub 仓库**：https://github.com/q1z2q3-debug/singbowl-healing-course
**许可证**：MIT（可自由使用、修改、传播）

教材围绕西藏颂钵（Tibetan Singing Bowl）与尼泊尔颂钵的疗愈原理展开，从钵体认知、声音振动科学、能量疗愈到实操案例，形成完整的颂钵音疗知识体系。

## 五大核心章节

| 章节 | 内容 |
|------|------|
| 第一章 初识颂钵 | 钵之型、钵之名、钵之质、缘起与发展；颂钵基础、制作、选钵、鉴别与周边配件；使用技法 |
| 第二章 理论课题 | 声音基础、振动基础、能量基础（三脉七轮）、疗愈原理、脉轮节奏、穴位经络 |
| 第三章 实践操作 | 16 类案例实操、颂钵音乐会演奏、个案精品体验流程 |
| 第四章 高级智慧 | 人生观、世界观、价值观、疗愈师专业要求、元气自我修复 |
| 第五章 自然疗法 | 呼吸、瑜伽、芳香、音乐、水晶、饮食、香道、冥想、气功 |

## 适用人群

- 颂钵疗愈师初学者
- 瑜伽/冥想导师
- 身心疗愈从业者
- 自然疗法爱好者
- 声音疗愈研究者
