# 教材开源发布公告：颂钵疗愈师培训教材 v7.0 上线

> **Singing Bowl Healing Course v7.0 is now open source — 全过程公开、无版权门槛、随缘流通。**

今天，**《颂钵疗愈师培训教材（7.0 大字版）》** 正式以 **MIT License** 开源发布，托管于 GitHub：

🔗 **仓库地址**：[https://github.com/q1z2q3-debug/singbowl-healing-course](https://github.com/q1z2q3-debug/singbowl-healing-course)

🌐 **在线阅读**：[https://q1z2q3-debug.github.io/singbowl-healing-course/](https://q1z2q3-debug.github.io/singbowl-healing-course/)

## 教材亮点

- **五大章节系统课程**：初识颂钵 → 理论课题 → 实践操作 → 颂钵生命智慧（高级）→ 自然疗法（初中高）
- **约 6300 行完整讲义**（大字版），附参考资料与常用颂钵药材对照表
- **中英双语**：核心章节英文版陆续上线（docs/en/）
- **互动功能**：站内全文搜索、章节自测题、阅读进度书签、Giscus 评论
- **合规开源**：MIT License，可自由使用、学习、分享、二次创作

## 为什么开源？

颂钵疗愈的传播，不在于门户之见，而在于让更多人**认识声音、认识自己**。开源意味着：

1. 任何有心人都可以免费获得完整教材
2. 疗愈师、培训机构可在注明出处的前提下用于教学
3. 社区可共同修订、翻译、完善，让内容持续进化

## 常见问题

**Q：可以用于商业培训吗？**
可以。MIT License 下允许商业使用，仅需保留版权声明。

**Q：如何参与贡献？**
欢迎通过 GitHub Issues / Discussions 反馈勘误、提出改进，或提交 Pull Request。

**Q：与收费课程有什么关系？**
本教材为公开知识整理，独立成课；如参加线下实操课程，讲师会提供现场演练与个案督导支持。
