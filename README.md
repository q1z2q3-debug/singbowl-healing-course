# 颂钵疗愈师培训教材（Sings Bowl Healing Course）

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

> **开源颂钵疗愈教材** | 系统的颂钵音疗师培训课程资料，涵盖颂钵基础知识、声音疗愈理论、颂钵实践操作、身心疗愈技法、自然疗法五大章节。适合颂钵疗愈师入门、冥想爱好者、瑜伽导师及身心自愈学习者参考。

本仓库开源了一份完整的颂钵疗愈师培训教材，内容整理自《颂钵疗愈师培训 7.0》课程材料。教材围绕**西藏颂钵**（Tibetan Singing Bowl）与**尼泊尔颂钵**的疗愈原理展开，从钵体认知、声音振动科学、能量疗愈到实操案例，形成完整的颂钵音疗知识体系。

## 教材内容

### 五大核心章节

1. **第一章 初识颂钵** —— 钵之型、钵之名、钵之质、缘起与发展；颂钵基础、制作、选钵、鉴别与周边配件；使用技法（请钵、持钵、敲钵、磨钵、移钵、放钵、止音、丁夏等）。
2. **第二章 理论课题** —— 声音基础（型质合一、声音要素、基础钵音）、振动基础（同频共振、物理振动）、能量基础（三脉、七轮、三大能量、五大元素、科学认知）、疗愈原理、脉轮节奏、穴位经络（膀胱经、脾胃经、肺经、肝胆经、三焦经、心包经、带脉）。
3. **第三章 实践操作** —— 案例实操（气场清理、空间净化、单钵/三钵/七钵疗愈、失眠头痛、妇科调理等 16 类案例）、颂钵音乐会演奏、个案精品体验流程。
4. **第四章 颂钵生命智慧（高级）** —— 人生观、世界观、价值观、疗愈师专业基础要求、疗愈师元气自我修复。
5. **第五章 自然疗法（初中高）** —— 呼吸、瑜伽、芳香、颂钵、音乐、水晶、饮食、香道、冥想、气功等疗法。

文末附有「附件」章节与参考资料书目。
