# 搜索引擎提交操作指南

> 本仓库的 SEO 基础设施已就绪（Jekyll、Sitemap、robots.txt、Schema.org），以下为向主流搜索引擎主动提交站点的离线操作步骤。

---

## 1. Google Search Console（必需）

### 步骤（HTML 验证文件已部署）

✅ **步骤 1-4 已完成**：验证文件 `google54dd10e23c4eef09.html` 已推送至仓库根目录并可通过 GitHub Pages 访问。

你只需完成以下操作：

1. 访问 https://search.google.com/search-console
2. 点击 **添加属性** → 选择 **网址前缀**
3. 输入：`https://q1z2q3-debug.github.io/singbowl-healing-course/`
4. 选择验证方式 **HTML 文件**，点击 **验证**
   - 如果提示失败，等待 1-2 分钟（Pages 构建可能有延迟）后重试
5. 验证成功后，进入 **索引 → 站点地图**
6. 提交：`https://q1z2q3-debug.github.io/singbowl-healing-course/sitemap.xml`

### Sitemap URL

```
https://q1z2q3-debug.github.io/singbowl-healing-course/sitemap.xml
```

## 2. Bing Webmaster Tools（可选，覆盖 Bing + Yahoo + DuckDuckGo）

### 步骤

1. 访问 https://www.bing.com/webmasters
2. 使用 Microsoft 账号登录
3. 点击 **添加站点**
4. 输入：`https://q1z2q3-debug.github.io/singbowl-healing-course/`
5. 验证方式选择 **HTML 文件**（同 Google）或使用 **GitHub 账号关联**（Bing 支持直接导入 Google Search Console 数据）
6. 验证后进入 **配置我的站点 → 提交 Sitemap**
7. 提交相同的 sitemap.xml URL

### 快捷方式

> Bing 支持「从 Google Search Console 导入」，只需一次配置即可同步两边数据。

## 3. 百度搜索资源平台（国内搜索为主时推荐）

### 步骤

1. 访问 https://ziyuan.baidu.com
2. 登录百度账号
3. 添加站点：`https://q1z2q3-debug.github.io/singbowl-healing-course/`
4. 验证方式：**文件验证**（同 Google/Bing）或 **CNAME 验证**
5. 验证成功后进入 **站点属性 → 链接提交**
6. 选择 **自动提交 → Sitemap**，提交 sitemap.xml URL

## 5. 加速索引的其他技巧

- **社交媒体分享**：在 Twitter/X、LinkedIn、Reddit 等平台分享仓库链接，Google 会更快发现新页面
- **外链建设**：在知乎、Medium、简书、小红书等平台发布相关内容（含仓库链接）
- **GitHub 官方推荐**：仓库 Stars / Forks 数量会影响搜索引擎权重
- **定期更新内容**：保持仓库活跃，GitHub Pages 会自动重新构建并更新 sitemap 时间戳
