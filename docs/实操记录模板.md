# 实操记录模板

> 本文档为教材第三章每个实操案例提供引导式记录模板，帮助学员记录操作感受、难点与创新尝试。预填内容均来自教材原文（对应案例要点），空白区为学员填写区。请对照《实操速查表》使用。

---

## 使用说明

1. **每个案例一张记录卡**：先填基本信息，再对照"教材要点"逐项完成操作并勾选。
2. **感受优先于结论**：身体感受、情绪体验如实记录，不评判对错。
3. **难点即学习点**：记录卡顿、不顺手、被疗愈者反馈异常的位置，课后复盘或请教导师。
4. **创新尝试需标注**：与教材不同的手法、节奏或组合，务必注明"自创尝试"并记录效果，便于后续验证。

### 案例 3 · 清肠排便（3.1.3.3）

- 教材要点：下三轮（脐轮、胃轮、海底轮）；从肚脐开始顺时针；
  神阙穴敲3次→气海穴敲3次→大巨穴→大横穴→中脘穴→大横穴→大巨穴→气海穴→神阙穴；15—30分钟
